# Ring of Fire

A party drinking game for the crew. Open the site on a phone and tap **Add to Home Screen**: it then works with no internet. Rotate the phone sideways to mirror it to a TV.

Player names and scores stay on each phone and are never uploaded.

## Install

- **iPhone:** open the link in Safari, tap Share, then **Add to Home Screen**.
- **Android:** open the link in Chrome, tap the ⋮ menu, then **Add to Home screen** (or **Install app**).

Open it once while online. After that it works with no internet.
